# Jeff Bezos: API-First и Модульная Изоляция

## Ключевая философия (The Bezos API Mandate)
Все модули проектируются как независимые сервисы, которые общаются исключительно через четко документированные интерфейсы и контракты. Никаких скрытых связей, никакого прямого залезания в чужие кишки.

## Правила для агента:
1. **Изоляция компонентов:** Модуль `hh` ничего не знает о внутренностях `google_sheets` или `digest`. Любой модуль можно выкинуть или заменить, и ядро даже не дрогнет.
2. **Контракт интерфейса:** Каждый модуль реализует единый интерфейс (`BaseModule`, метод `get_actions()`, метод `run()`).
3. **Главная -> Модули -> Функции:** Пользовательский интерфейс и CLI отражают независимую архитектуру модулей.
4. **Легкое добавление без трения:** Добавление новой фичи (Telegram, Calendar, AI-ассистент) не требует изменения существующего проверенного кода.
